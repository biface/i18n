3.5.9. Exceptions¶

Every exception of the package derives from I18nToolsError: one except I18nToolsError clause catches any of them, and a subclass targets one kind of failure.

        flowchart TD
    base["I18nToolsError"]
    base --> FormatError
    base --> MessageError
    MessageError --> MessageNotFoundError
    base --> BookError
    base --> RepositoryError
    base --> LoaderError
    base --> ConversionError
    base --> LocaleError
    base --> FormatterError
    FormatterError --> PluralIndexError
    FormatterError --> VariantIndexError
    FormatterError --> PluralRuleError

PluralIndexError and VariantIndexError carry the message identifier and the requested index as fields, so that a caller can handle them without reading their text.

I18nToolsWarning reports a point to look at without stopping the operation, for instance a warning found while loading a file. warnings.simplefilter("error", I18nToolsWarning) turns it into an exception.

Base class¶

exception i18n_tools.exceptions.I18nToolsError¶

Base class for all i18n-tools exceptions.

Files and messages¶

exception i18n_tools.exceptions.FormatError¶

Raised when a .i18t file has an invalid or unexpected structure.

exception i18n_tools.exceptions.MessageError¶

Raised when an operation on a Message object fails.

exception i18n_tools.exceptions.MessageNotFoundError¶

Raised when a message identifier cannot be found in any Book of the fallback chain.

exception i18n_tools.exceptions.BookError¶

Raised when an operation on a Book object fails.

Repository, files and conversions¶

exception i18n_tools.exceptions.RepositoryError¶

Raised when a configuration or repository operation fails.

exception i18n_tools.exceptions.LoaderError¶

Raised when a file I/O operation in the loaders layer fails.

exception i18n_tools.exceptions.ConversionError¶

Raised when a format conversion (e.g. Babel Catalog ↔ Book) fails.

exception i18n_tools.exceptions.LocaleError¶

Raised when an IETF language tag is invalid or cannot be normalised.

Formatting¶

exception i18n_tools.exceptions.FormatterError¶

Raised when formatting/publishing a Message fails.

exception i18n_tools.exceptions.PluralIndexError(message_id: str, segment: int, segments: int)¶

Raised when a segment (plural row) does not exist on the Message.

The segment was either given explicitly or resolved by the Message’s PluralRule. The fields let a caller handle the error without reading its text.

Parameters:

  • message_id (str) – Identifier of the message.

  • segment (int) – The requested segment.

  • segments (int) – Number of segments of the message.

exception i18n_tools.exceptions.VariantIndexError(message_id: str, variant: int, variants: int)¶

Raised when a variant (column) does not exist on the Message.

Parameters:

  • message_id (str) – Identifier of the message.

  • variant (int) – The requested variant.

  • variants (int) – Number of declensions of the message, principal included.

exception i18n_tools.exceptions.PluralRuleError¶

Raised when a PluralRule configuration is invalid (e.g. malformed thresholds).

Warning¶

class i18n_tools.exceptions.I18nToolsWarning¶

Warned when data is usable but has a point the user has to look at.
