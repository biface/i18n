Loader module¶

class i18n_tools.loaders.loader.LocaleStructure¶

Where aggregate_locale_json() looks for locale files.

base is the root directory; modules lists the module paths under it, each holding a locales directory.

i18n_tools.loaders.loader.load_locale_json(file_path: Path | str) → dict[str, JSONValue]¶

This function load a JSON file in the locales repository and containing i18next data. The structure of this dictionary is as follows:

{
    "msgid_001": [
            ["msgstr_001_000", "msgstr_001_001"],
            ["msgplr_001_1_000", "msgplr_001_1_001"],
            ["msgplr_001_2_000", "msgplr_001_2_001"]
        ],
    "msgid_002": [
            ["msgstr_002_000"],
            ["msgplr_002_1_000"],
            ["msgplr_002_2_000"]
        ]
}
Parameters:

file_path (Path | str) – Path to the JSON locale file.

Returns:

JSON locale data content.

Return type:

dict

Raises:

  • FileNotFoundError – If the file is not found.

  • ValueError – If the file is not a valid JSON or fails the integrity check.

i18n_tools.loaders.loader.load_book(file_path: str, language: str | None = None, domain: str | None = None) → BookData¶

Read a Book file and return its content as format 1.0.0 reads it.

The encoding is detected from the name of the file, symmetrically to save_book(). The content is checked against language and domain when given, by the rules of the format reference. Errors stop the load; warnings are issued as I18nToolsWarning and the content is returned; information findings are neither raised nor issued.

Parameters:

  • file_path (str) – Path to the .i18t translation file.

  • language (str | None) – The normalized language the file should hold, or None to skip the comparison.

  • domain (str | None) – The domain the file should hold, or None to skip the comparison.

Returns:

The root metadata and the entries, as read.

Return type:

BookData

Raises:

  • FileNotFoundError – If the file does not exist.

  • FormatError – If the name is not a Book name, the content does not parse, or it has errors; the message lists every error.

i18n_tools.loaders.loader.inspect_book_file(file_path: str, language: str | None = None, domain: str | None = None) → list[Finding]¶

Check a .i18t file and list what is wrong with it, without loading it.

The file is read in the format given by its extension (DD-34) and checked by the same rules as load_book(), against language and domain when given. Unlike load_book(), nothing is raised for the content and nothing is warned: every finding, of every severity, is returned. A content that cannot be parsed, or is not a mapping, gives one error finding about the root of the file.

Parameters:

  • file_path (str) – Path to the .i18t translation file.

  • language (str | None) – The normalized language the file should hold, or None to skip the comparison.

  • domain (str | None) – The domain the file should hold, or None to skip the comparison.

Returns:

The findings, in file order; empty if nothing is wrong.

Return type:

list[Finding]

Raises:

  • TypeError – If file_path is not a string, or language or domain is neither a string nor None.

  • FileNotFoundError – If the file does not exist.

i18n_tools.loaders.loader.save_book(book: Book, file_path: str) → None¶

Write a Book to a .i18t file in format 1.0.0.

The encoding (JSON or YAML) is detected from the name of the file. The root metadata is that of the Book, with format_version "1.0.0" and the count and statistics computed from the entries; each entry is written under the key the Book holds the message by, which is also its id. Keys are written in the order of the format reference, metadata first.

Parameters:

  • book (Book) – The Book instance to persist.

  • file_path (str) – Full path (directory + filename) of the target .i18t file.

Raises:

FileNotFoundError – If the parent directory does not exist.

i18n_tools.loaders.loader.aggregate_dictionaries(repository: StrictNestedDictionary, module: str, domain: str) → None¶

This function aggregates all dictionaries for a given module and domain into a single JSON file.

Parameters:

  • repository (StrictNestedDictionary) – The data structure which represents the repository information.

  • module (str) – module where translation should be located.

  • domain (str) – domain of translation.

Returns:

Nothing

Return type:

None

Raises:

Exception – If any error occurs during the aggregation.

i18n_tools.loaders.loader.aggregate_locale_json(structure: LocaleStructure, domains: dict[str, list[str]], languages: dict[str, list[str]]) → dict[str, dict[str, dict[str, dict[str, JSONValue]]]]¶

Aggregate JSON locale files based on the given structure, domains, and languages.

Distinct from aggregate_dictionaries(): this function works from generic, caller-supplied parameters (no Repository instance, no embedded metadata) and reads files directly from disk by path. Kept alongside it as a separate, legitimate responsibility — not a duplicate (DD-NN, #69).

Parameters:

  • structure (LocaleStructure) – Dictionary containing ‘base’ path and list of ‘modules’.

  • domains (dict[str, list[str]]) – Dictionary where keys are module names and values are lists of domains.

  • languages (dict[str, list[str]]) – Dictionary where keys are language codes and values are lists of regional variants.

Returns:

The locale data of each variant, by module, then domain, then variant.

Return type:

dict[str, dict[str, dict[str, dict[str, JSONValue]]]]

i18n_tools.loaders.loader.save_locale_json(file_path: str, data: Mapping[str, JSONInput]) → None¶

Save data to a JSON locale file.

Parameters:

  • file_path (str) – Path to the JSON locale file.

  • data (dict) – Dictionary containing locale data.

Raises:

FileNotFoundError – If the directory for the file is not found.

i18n_tools.loaders.loader.save_aggregated_locale_json(aggregated_data: Mapping[str, Mapping[str, Mapping[str, JSONInput]]], base_path: str) → None¶

Save the aggregated locale JSON data as gzipped files for each domain in the locales directory, and create a gzipped file for the entire module or sub-module at the base of its directory.

Companion to aggregate_locale_json() — see that function’s docstring for why it is kept distinct from aggregate_dictionaries() (DD-NN, #69).

Parameters:

  • aggregated_data (dict) – The aggregated dictionary of locale data.

  • base_path (str) – The base path where the locales directories are located.

i18n_tools.loaders.loader.build_book_filename(domain: str, fmt: Literal['json', 'yaml'] | None = None) → tuple[Literal['json', 'yaml'], str]¶

Pass-through to i18n_tools.loaders._handler.build_book_filename().

Kept here so that Book (models/book.py) only ever talks to loader.py, consistent with the existing load_book/save_book pattern (DD-06, DD-08) — never directly to handler.py.

Parameters:

  • domain (str) – The translation domain name.

  • fmt (TranslationFileFormat | None) – The desired storage format (“json” or “yaml”). Defaults to “json” if None.

Returns:

A (format, filename) tuple.

Return type:

tuple[TranslationFileFormat, str]

Raises:

ValueError – If fmt is not a recognised translation format.
