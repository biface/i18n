Handler module (internal)¶

Intermediate layer for path and file type management. Internal module: imported by the loader module only.

class i18n_tools.loaders._handler.BookData¶

Content of a Book file as read, in format 1.0.0.

metadata holds format_version, version, language, domain, gettext (its seven keys) and rules, absent values replaced as the format says. entries maps each identifier to its entry: messages (principal, alternatives) and metadata (id, context, locations, flags, user_comments, auto_comments, status, rules, and count and fill_mask when the entry has a record). The root count and statistics and the entry statistics are not kept: a writer computes them.

Constructs, cleans, and validates a path by combining a base path with one or more subdirectories.

i18n_tools.loaders._handler.build_book_filename(domain: str, fmt: Literal['json', 'yaml'] | None = None) → tuple[Literal['json', 'yaml'], str]¶

Resolve the storage format (default + validation) and the corresponding .i18t filename for a translation domain, without requiring a Book instance.

This is the single place where the default-format and filename-building rules for a translation dictionary are applied — used by Book (via loader.py, never imported here directly, DD-06) to keep its own file format default/validation consistent across its constructor and its add_file_format()/update_file_format() methods, and reusable from core.py, sync.py, or a future CLI without constructing a Book first.

Parameters:

  • domain (str) – The translation domain name.

  • fmt (TranslationFileFormat | None) – The desired storage format (“json” or “yaml”). Defaults to “json” if None.

Returns:

A (format, filename) tuple, e.g. ("json", "messages.json.i18t").

Return type:

tuple[TranslationFileFormat, str]

Raises:

ValueError – If fmt is not a recognised translation format.

i18n_tools.loaders._handler.check_json_integrity(data: Mapping[str, JSONInput]) → bool¶

Check the integrity of translation data.

Every entry other than the reserved .i18n_tools and metadata keys takes one of two forms:

  • {"messages": matrix, "metadata": {...}}, the native .i18t entry; metadata is optional and must be a dictionary;

  • a bare matrix, the legacy flat form, still readable.

In both forms the matrix must pass the checks of _check_matrix().

Parameters:

data (dict) – The translation data.

Returns:

True if the data is valid, False otherwise.

Return type:

bool
