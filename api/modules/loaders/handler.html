4.5.2. Handler module¶

This module handles the manipulation of files within the repository using utils.py. It calculates paths, controls file names and access, and retrieves data contained in translation files.

Key Responsibilities:

  • Manipulate files within the repository.

  • Calculate paths, control file names and access.

  • Retrieve data from translation files.

i18n_tools.loaders.handler.build_path(base_path: str, *sub_dirs: str) → str¶

Constructs, cleans, and validates a path by combining a base path with one or more subdirectories.

This function ensures that the constructed path does not contain any elements that could corrupt the path, such as ‘..’. It also verifies that the path exists.

Parameters:

  • base_path (Union[Path, str]) – The starting path.

  • sub_dirs (str) – One or more subdirectory names to append to the base path.

Returns:

The combined, cleaned, and validated path as a string.

Return type:

str

Raises:

IOError – If the constructed path is invalid or does not exist.

i18n_tools.loaders.handler.build_book_filename(domain: str, fmt: Literal['json', 'yaml'] | None = None) → tuple[Literal['json', 'yaml'], str]¶

Resolve the storage format (default + validation) and the corresponding .i18t filename for a translation domain, without requiring a Book instance.

This is the single place where the default-format and filename-building rules for a translation dictionary are applied — used by Book (via loader.py, never imported here directly, DD-06) to keep its own format default/validation consistent across its constructor and its add_format()/update_format() methods, and reusable from core.py, sync.py, or a future CLI without constructing a Book first.

Parameters:

  • domain (str) – The translation domain name.

  • fmt (TranslationFileFormat | None) – The desired storage format (“json” or “yaml”). Defaults to “json” if None.

Returns:

A (format, filename) tuple, e.g. ("json", "messages.json.i18t").

Return type:

tuple[TranslationFileFormat, str]

Raises:

ValueError – If fmt is not a recognised translation format.
