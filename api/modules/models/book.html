Book module¶

class i18n_tools.models.book.BookOptions¶

Keyword contract of Book.

language and domain are required; file_format defaults to "json". Any other key is refused with a TypeError. The gettext fields are set by Book.set_gettext() and the version by Book.version.

class i18n_tools.models.book.Book(*args: Message | tuple[Message] | list[Message], **kwargs: Unpack[BookOptions])¶

The messages of one domain in one language: the content of one .i18t file.

The metadata attribute holds the keys of the root metadata of the file: format_version (the version of the format read, "1.0.0" for a new Book), version, language, domain, gettext and rules. The properties of the same names read these keys. count and statistics are computed when the file is written.

The class is iterable: iterating over a Book yields its Message instances in insertion order. The messages attribute maps each identifier to its message. The Book is the master of these keys: add() holds a message under its id, rename() changes the key and the id together, and the file takes the key as the id of the entry.

Variables:

  • file_format – Storage encoding of the file ("json").

  • filename – Name of the file, <domain>.<file_format>.i18t.

  • messages – Identifier to Message.

  • metadata – The root metadata.

  • plural_rule – Rule of the Book, or None.

load(path_directory: str) → None¶

Load the root metadata and the messages of a .i18t file into this Book.

The file is path_directory/self.filename. It is checked against the language and the domain of this Book by the rules of the format (loader.load_book()). The root metadata of the file replaces that of the Book; each entry becomes a message held under its key, with its status and its record as read.

Parameters:

path_directory (str) – Directory containing the .i18t file.

Raises:

  • FileNotFoundError – If the file does not exist.

  • FormatError – If the file content has errors.

save(path_directory: str) → None¶

Save the content of this Book to a .i18t file.

The file is path_directory/self.filename, written by loader.save_book() in format 1.0.0. po_revision_date takes the date and time of the write. A complete message that diverges from its record, or has none, is never written over the last sound state: the save is refused before anything is written. Once the file is written, each draft records its content (Message.record()): saving a draft is a validation point.

Parameters:

path_directory (str) – Directory where the .i18t file will be written.

Raises:

  • MessageError – If a complete message diverges.

  • FileNotFoundError – If path_directory does not exist.

check() → list[Finding]¶

Check the integrity of the messages of this book.

A "draft" message is reported with severity "info": an empty principal singular or content that differs from its record is expected while a translation is in progress. The same points on a "complete" message are integrity defects, reported with severity "error", as is a complete message without a record. Nothing is raised.

Returns:

The findings, in message order; empty if nothing is wrong.

Return type:

list[Finding]

set_metadata(key: str | list[str] | None, value: JSONInput = None) → None¶

Set, or reset to its default with value=None, a key of the root metadata.

version, language and domain go through their property; a path ["gettext", <field>] sets one gettext field; rules and any path inside it are written as given, the content of rules being open. format_version, count and statistics cannot be set.

Parameters:

  • TypeError – If key is neither a string nor a list of strings, or a value has the wrong type.

  • ValueError – If a value is refused by its property.

class i18n_tools.models.book.FallbackBook(chain: list[Book], language: str)¶

Transparent proxy over an ordered list of Books implementing the fallback chain.

FallbackBook is never instantiated directly by the user — it is constructed by Corpus.get_book() from the chain of available Books that match the requested language (DD-09b).

For each get_message() call the chain is walked in order; the first Book that contains the requested identifier wins. If no Book in the chain holds the identifier, MessageNotFoundError is raised.

The column fallback (DD-27) is orthogonal: it operates inside a single Message object and is handled by formatter.publish().

References

  • biface/i18n#43 : Corpus / FallbackBook proxy design (DD-09, DD-09b)

  • biface/i18n#20 : MessageNotFoundError (DD-24)
