Message module¶

class i18n_tools.models.message.Declension(singular: str = '', plurals: tuple[str, ...] = ())¶

One singular text and zero or more plural texts.

The principal of a message and each of its variants are declensions. Segment 0 is the singular, segments 1 to n are the plurals: a singular with three plurals has four segments. An empty string marks an absent text.

A declension is immutable: a message changes its content by replacing whole declensions, so that every change goes through the methods of Message.

Parameters:

  • singular (str) – Text of segment 0.

  • plurals (tuple[str, ...]) – Texts of segments 1 to n, in order.

Raises:

TypeError – If a text is not a string, or plurals is not a tuple.

Keyword contract for the texts of one declension.

class i18n_tools.models.message.MessageOptions¶

Keyword contract of Message: the texts beyond the principal singular and the metadata of the entry, all optional.

alternatives holds the texts of each alternative, singular first. status, count and fill_mask are not options: they are set by Message.mark_complete(), Message.reopen() and Message.record().

class i18n_tools.models.message.Message(id: str | int, singular: str = '', **options: Unpack[MessageOptions])¶

One identifier’s texts and metadata, in one language.

The content of a message is a principal declension and zero or more variant declensions. A text is addressed by (variant, segment): variant=0 is the principal, variant=1 the first variant; segment=0 is the singular, segment=1 the first plural.

The principal always exists as a structure: an absent principal is a declension whose singular is "". "" marks an absent text anywhere in the content.

Declensions may have different numbers of segments while a message is edited. matrix pads the shorter ones with "".

The metadata attribute holds the keys of the entry metadata of a .i18t file: id, context, locations, flags, user_comments, auto_comments, status, rules, and count and fill_mask once a record is taken. The properties of the same names read these keys.

A message is "draft" or "complete". mark_complete() records the content and locks the texts and the structure; reopen() makes the message a draft again; record() records the content of a draft (a draft save). Context, locations, flags, comments and rules stay editable in both states.

Variables:

  • metadata – The entry metadata.

  • plural_rule – Rule resolving a count to a segment, or None.

classmethod from_matrix(id: str | int, matrix: list[list[str]], **options: Unpack[MessageOptions]) → Message¶

Build a draft message from its matrix.

The matrix has the orientation of the format of 0.10.0: one row per segment (row 0 holds the singulars), one column per declension (column 0 is the principal). Each column becomes a declension with all its cells, empty strings included, so that Message.from_matrix(id, m).matrix == m.

Parameters:

  • id (str | int) – Identifier of the message, as accepted by the constructor.

  • matrix (list[list[str]]) – Rows of texts; at least one row, all rows of the same non-zero length.

  • options (MessageOptions) – The metadata options of the constructor; the texts come from the matrix.

Returns:

The message.

Return type:

Message

Raises:

  • TypeError – If matrix or one of its rows is not a list, a cell is not a string, or an option is refused.

  • ValueError – If matrix is empty or not rectangular.

add_location(file: str, line: int, variant: int | None = None, segment: int | None = None) → None¶

Add a place in source code that uses the message.

variant and segment locate the text used at that place; None leaves the coordinate open. They are not checked against the content: source code may refer to a text not written yet. A location already present is not added twice. Locations stay editable on a complete message.

Parameters:

  • line (int) – Line number in that file, starting at 1.

  • variant (int | None) – Declension used there, if fixed.

  • segment (int | None) – Segment used there, if fixed.

Raises:

  • TypeError – If an argument has the wrong type.

  • ValueError – If file is empty, line is below 1 or a coordinate is negative.

i18n_tools.models.message.extract_tokens(text: str) → list[str]¶

List the tokens of a text, in order of appearance.

A token is a replacement field of str.format with a name; its name is the field name, without conversion or format specification ({n:d} and {n} are the token n). Doubled braces are literal braces, and a positional field ({}, {0}) is not a token.

Parameters:

text (str) – The text to read.

Returns:

The token names, repeated if a token appears several times.

Return type:

list[str]

Raises:

ValueError – If the text is not a valid format string.

class i18n_tools.models.ContentCounters(record: Mapping[str, object] | None = None, *, default_setup: Mapping[str, object] | None = None)¶

The record of a message: its count and its fill_mask.

A view on the two keys of the entry metadata, with the paths of the file: counters[["count", "segments", "principal"]]. Built on the nodes of a message, it holds them, not copies: a change of the message metadata is seen through it. Two records are equal when their content and their settings are equal.

The constructor takes the record, or nothing: ndict-tools copies an object by building an empty one and filling its keys.

Parameters:

  • record (Mapping[str, object] | None) – A mapping with count and fill_mask, or None for an empty record.

  • default_setup (Mapping[str, object] | None) – Settings of the nested dictionary, passed on unchanged.

Raises:

TypeError – If record is not a mapping with count and fill_mask.
